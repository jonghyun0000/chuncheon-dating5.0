# 춘천과팅 Android 비공개 테스트 안내 초안

운영자가 아래 항목을 채운 뒤 참가자에게 전달한다. 아직 배포·참여가 시작됐다는 뜻이 아니다.

- 참여 링크: **Console에서 복사한 링크 입력 필요**
- 테스트 기간: **실제 시작 후 입력**
- 피드백 이메일/폼: **운영자 확인 필요**
- 테스트 대상 버전: **versionName·versionCode 입력 필요**
- 연결 환경: **운영 공통 데이터 / 별도 테스트 데이터 중 실제 빌드 환경을 명시**

## 참여 방법

1. 운영자에게 알려준 **같은 Google 계정**으로 Android의 Play 스토어와 참여 링크를 연다.
2. 참여 페이지에서 테스트 참여를 선택한 뒤 Play 스토어를 통해 설치한다. 이메일 명단에만 올라간 상태는 참여 완료가 아니다.
3. 기존 춘천과팅 회원이면 기존 아이디로 로그인한다. 웹 로그인 상태는 앱으로 자동 이전되지 않는다. 다른 테스트 환경이라면 운영자가 제공한 별도 안내를 따른다.
4. 비공개 테스트 참여 상태를 연속 14일 동안 유지하고 실제 사용 중 발견한 점을 전달한다. Google의 최소 조건은 12명이며, 14일 후 자동 정식 출시되는 것은 아니다. [Google 공식 안내](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko)

내부 테스트에 참여했었다면 내부 테스트에서 먼저 나간 뒤 이 비공개 테스트 참여를 선택한다. 설치가 안 되면 사용한 Google 계정·참여 상태·배포 국가·기기 호환 여부를 운영자와 확인한다. 계정 비밀번호는 보내지 않는다. [Google 테스트 안내](https://support.google.com/googleplay/android-developer/answer/9845334?hl=ko)

## 확인할 내용

| 시점 | 확인할 흐름 |
| --- | --- |
| 처음 설치 | 꽃 로고·앱 이름, 시작 화면, 로그인, 약관·학생증 제출 안내 |
| 팀 등록 | 학교·학과·학번·닉네임 입력, 팀원 사진 선택/취소/변경/삭제, 키보드로 버튼이 가려지는지 |
| 둘러보기 | 팀 목록·사진 확대, 같은 학교·학과 지인 피하기의 설명과 설정 |
| 신청 | 운영자가 지정한 상대와 신청·수락·상태 확인. 무관한 실제 회원에게 시험 신청을 보내지 않기 |
| 기기 동작 | Android 뒤로가기, 홈으로 나갔다 복귀, 화면 회전, 통신 끊김 후 재시도 |
| 외부 연결 | 문의 버튼에서 메일 앱 열기, 광고 링크에서 외부 페이지 이동·복귀 |
| 업데이트 | 새 테스트 버전 설치 후 로그인·기존 팀·설정 유지 |
| 안전·탈퇴 | 운영자가 정한 테스트 계정에서 신고·차단·탈퇴 흐름 확인. 아직 없는 기능은 있다고 가정하지 말고 기록 |

앱의 현재 이용약관은 만 19세 이상 대상 대학 학생을 기준으로 한다. 다른 사람의 사진·학생증을 빌려 가입하지 않는다. 심사·기능 검증용 가상 계정이 필요하면 운영자가 별도로 제공해야 한다.

**운영 데이터에 연결된 버전에서는 팀 등록·신청·사진 삭제·탈퇴가 실제 웹 서비스에도 반영된다.** 운영자가 안내한 범위에서만 진행한다. 학생증·전화번호·타인의 프로필이 보이는 화면은 피드백에 그대로 첨부하지 않는다.

## 오류 전달 양식

```text
앱 버전:
기기 모델 / Android 버전:
발생 날짜·대략적인 시각:
어느 화면에서 무엇을 눌렀는지:
기대한 결과 / 실제 결과:
다시 해도 발생하는지:
개인정보를 가린 화면 캡처(선택):
```

비밀번호·학생증 원본·타인의 연락처는 보내지 않는다. 테스트 참여는 언제든 중단할 수 있으며, 중단하면 해당 참가자의 연속 참여 조건에 영향을 줄 수 있다. 운영자는 참여 강요나 허위 피드백 작성을 요구하지 않는다.
