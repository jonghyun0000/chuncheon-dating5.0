# 춘천과팅 아동 안전 기준 — 검토용 초안

작성일: 2026-11-18. **아직 공개·시행·Console 제출하지 않은 초안**이다. 아래 공개 문구와 실제 운영 절차를 운영자가 승인하고, 담당자·신고 경로·공개 URL을 확인한 뒤 게시한다. 기존 앱의 이용약관·개인정보처리방침을 대체하지 않는다.

## 공개할 문구 초안

### 이용 대상과 원칙

춘천과팅은 만 19세 이상을 대상으로 하는 대학생 팀 만남 서비스입니다. 아동·청소년에 대한 성적 학대 및 착취(CSAE)를 금지합니다. 이 기준은 팀 소개, 닉네임, 사진, 후기, 신고 내용, 외부 링크와 서비스를 통해 이어지는 만남 관련 행위에 적용합니다.

학생증 사진 등록과 운영자의 학생 인증은 서로 다른 절차입니다. 학생 인증 뱃지는 상대방의 안전성이나 신원을 보장하지 않습니다. 연령 확인 입력도 공식 신분 확인을 대신하지 않습니다.

### 금지하는 행위

- 아동·청소년을 성적으로 학대·착취하는 이미지·영상·글·링크를 게시하거나 요청·제공하는 행위. 실제 촬영물뿐 아니라 그러한 내용을 담은 합성·생성물도 포함합니다.
- 아동·청소년을 성적 목적으로 유인하거나 친분을 쌓아 착취하는 행위, 성적 이미지나 만남을 요구하는 행위.
- 성적 자료를 이용한 협박, 금품 요구, 인신매매 또는 착취를 알선·조장하는 행위.
- 위 행위를 숨기거나 계속하기 위해 다른 계정, 팀, 외부 메신저·사이트로 유도하는 행위.

### 신고 방법

앱의 **신고하기**에서 문제가 된 팀·회원과 상황을 알려주세요. 기존 분류에 맞는 항목이 없으면 ‘기타’를 선택할 수 있습니다. 접근이 어렵거나 별도 문의가 필요한 경우 아래 아동 안전 연락처를 이용할 수 있습니다.

- 아동 안전 문의: **[운영자 확정 후 이메일 입력]**
- 알려주실 정보: 해당 팀·회원의 서비스 내 식별 정보 또는 링크, 발견한 시각, 문제 상황의 간단한 설명.

불법으로 의심되는 사진·영상을 새로 내려받거나 복제하여 보내지 마세요. 비밀번호, 전체 학생증, 다른 사람의 불필요한 개인정보도 보내지 마세요. 현재 신체적 위험이 있는 경우 앱 신고와 별도로 현지 긴급 대응기관의 도움을 요청하세요.

### 확인 및 조치

담당자는 신고와 발견된 내용을 검토하고, 아동·청소년에게 위해가 될 가능성과 추가 노출 위험을 우선 확인합니다. 필요한 경우 검토 중에도 해당 콘텐츠의 노출 또는 계정의 이용을 제한할 수 있습니다. 금지된 콘텐츠로 확인된 경우 접근을 차단하고 삭제하며, 위반 계정에는 이용 제한 등 조치를 취합니다.

신고 내용과 처리 기록은 안전 조치에 필요한 담당자만 다룹니다. 신고자의 개인정보를 다른 회원에게 공개하지 않습니다. 다만 적법한 기관 요청 등 별도의 근거가 있는 경우 해당 범위에서 처리할 수 있습니다. 안전 조치에 필요한 최소한의 기록과 법령상 필요한 자료의 보존·제공은 개인정보처리방침 및 적용 법령에 따라 관리합니다.

운영자는 아동 성적 학대 자료(CSAM) 또는 착취 정황을 알게 된 경우 적용 법령상 신고 의무와 관할을 확인하여 필요한 기관 신고와 협조를 진행합니다. 조치에 대한 이의나 추가 정보는 아동 안전 문의 창구로 전달할 수 있습니다.

### 기준 변경

변경되는 기준과 시행일은 이 페이지에 게시합니다. 공개된 설명과 실제 신고·관리 기능이 일치하도록 점검합니다.

## 운영자 절차 초안 — 공개 문구와 함께 검증

1. **접수:** 기존 신고 ID와 대상 팀·회원·콘텐츠 ID, 접수 시각을 기록한다. 신고자의 불필요한 신원 정보와 원본 이미지를 별도 문서·이메일·채팅으로 복사하지 않는다.
2. **위험 판단:** 미성년 관련성, 착취 정황, 현재 위험, 재노출 가능성을 살핀다. 긴급 위험은 우선 처리하고 필요한 외부 기관 대응 여부를 판단한다. 확인되지 않은 신고를 곧바로 사실로 단정하지 않는다.
3. **노출 중단:** 필요한 팀·사진·후기 접근을 제한한다. 실제 Storage 원본·다운로드 경로·캐시 접근까지 확인하여 UI에서만 숨긴 상태로 끝내지 않는다. 통상적인 팀 사진 90일 보관 규칙을 위법 의심 자료의 자동 보존 근거로 삼지 않는다.
4. **검토·결정:** 검토자·판단 근거·조치 시각·대상 식별자 중심으로 기록한다. 허가된 담당자만 확인하고, 검토 편의를 위한 유해 이미지 복제본을 만들지 않는다.
5. **기관 대응:** 지정 책임자가 관할·법정 신고 및 보존 의무를 확인한다. 필요한 경우 적절한 전문가의 검토를 거쳐 해당 기관에 적법하고 안전한 방식으로 전달한다. 특정 해외 기관으로 모든 사건을 무조건 전송한다고 선언하지 않는다.
6. **종료·재발 대응:** 계정 제한과 콘텐츠 삭제 결과를 확인하고 필요한 범위에서 신고자에게 처리 상태를 안내한다. 이의·추가 신고를 접수하고 동일 콘텐츠·계정 재발 여부를 검토한다. 기록의 보관 사유·기간 및 종료 후 삭제를 정한다.

공개 전에는 실제 회원이나 유해 자료를 사용하지 않고 **가상 팀·무해한 테스트 신고**로 접수 → 관리자 조회 → 접근 제한 → 처리 상태 → 문의 경로를 검증한다. 현재 새로 준비 중인 개별 사용자 차단은 운영 DB 적용·검증 전까지 이미 제공되는 보호 기능으로 홍보하지 않는다.
