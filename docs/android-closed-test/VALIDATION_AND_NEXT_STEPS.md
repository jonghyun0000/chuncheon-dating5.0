# Android 비공개 테스트 준비 결과

확인일: 2026-11-18. **검토용 후보이며 Play 업로드·심사·비공개 테스트 참여는 아직 시작하지 않았다.** 운영 웹과 DB 변경도 하지 않았다.

## 준비한 결과물

- 서명 AAB와 직접 설치 검증용 APK: `release-candidates/android/`.
- 앱 식별자 후보 `kr.hyundo.chuncheondating`, `1.0.0-beta.1`, versionCode `1`, Android 최소 API 24·대상 API 36.
- 실제 공통 Supabase 백엔드의 공개 설정을 포함한다. 웹 회원·팀 데이터를 공유하는 후보이며 별도 샌드박스 앱이 아니다. 이번 검증은 실제 회원 데이터 변경 없이 수행했다.
- 기존 꽃 로고의 런처·적응형 아이콘, Play용 아이콘·1024×500 홍보 그래픽. 실제 Android 화면 캡처는 미완료다.
- [Console 실행 안내](RUNBOOK.md), [테스터 안내문](TESTER_GUIDE.md), [등록정보 초안](STORE_LISTING_DRAFT.md), [아동 안전 기준 초안](CHILD_SAFETY_POLICY_DRAFT.md), [데이터 보안 검토표](DATA_SAFETY_WORKSHEET.md).
- 개별 계정 차단 SQL·UI와 로컬 테스트. 운영 적용 전에는 UI에서 기능을 활성화하지 않는다. 같은 학교·학과 지인 피하기와 관리자 권한은 유지한다.
- 네이티브 앱의 만 19세 이상 자기신고 화면. 생년월일은 저장·전송하지 않으며, 기기 내 확인 결과는 본인·연령의 서버 검증을 대신하지 않는다.

## 서명과 재현

```sh
# 공개 URL/공개 키만 .env.native.local에 설정한다.
# JAVA_HOME은 JDK 21, ANDROID_HOME은 SDK 36 설치 경로를 지정한다.
npm run mobile:android:bundle
node scripts/create-android-store-assets.mjs
```

업로드 키는 저장소 밖 `~/.config/chuncheon-dating/android-signing/`에 만들었다. 파일 권한은 사용자 전용이다. **키·비밀번호 파일을 공개 Git, 리뷰 ZIP, 이메일에 넣지 않는다.** 첫 업로드 전 별도의 안전한 백업과 기존 앱/업로드 키 존재 여부를 확인한다. 이번에 만든 키는 아직 Play에 등록하지 않았다.

정확한 소스 커밋·AAB SHA-256·인증서 지문은 각 후보의 `BUILD_REPORT.json`을 기준으로 한다. 재빌드하면 파일 해시가 달라질 수 있다. 실제 배포 시 버전 코드는 증가시킨다.

## 테스트 공개 전 남은 작업

1. **Console 앱·기존 업로드 여부 확인.** 개발자 계정만 만든 상태인지, 앱 항목 생성 또는 AAB 업로드 이력이 있는지 확인하여 식별자와 서명을 확정한다. 연결된 도구로 Console을 직접 확인하지 못했다.
2. **운영 DB 접근 복구와 SQL 승인.** 현재 Supabase 연결에서 춘천과팅 프로젝트 접근이 거부된다. 권한 있는 연결을 복구하고 아래 SQL을 검토·승인한 뒤 적용한다. 활성 일반 계정의 `user_blocking_available()`이 `true`이고 실제 차단 시 양방향 노출·신청·사진 접근이 막히는지 확인해야 한다. SQL 적용 없이 이 후보를 테스트 참가자에게 배포하지 않는다.
3. **삭제·보관 및 공개 정책 보완.** 관리자 처리 대기와 공개 즉시 삭제 안내의 불일치를 해결하고, 계정·학생증·사진의 실제 삭제와 남기는 데이터의 목적·기간을 검증한다. 아동 안전 공개 URL·담당자·처리 절차, 개인정보·데이터 보안·광고·연령 선언을 확정한다.
4. **실기기·심사 계정·이미지.** 실제 Android에서 일반/관리자 기능을 확인한다. 별도 일반 심사 계정과 가상 데이터·접근 설명, 실제 앱 스크린샷을 준비한다. 운영 관리자 계정이나 실제 회원 자료를 심사 자료로 공유하지 않는다.
5. **기존 필수 감사와 배포 검사 통과.** 미해결 의존성 공지를 해결하고 필수 검사를 유지한다. PR은 draft이며 운영 병합하지 않는다.
6. **Console 제출 후 실제 테스트 개시.** 앱 콘텐츠·등록정보를 완료하고 비공개 트랙에 승인된 AAB를 제출한다. Console에서 실제 참여 링크를 확인한 뒤 참가자에게 안내한다.

개인 계정의 최소 조건은 **12명 이상, 연속 14일 참여 상태 유지**이다. 모집은 여유 있게 15~20명을 권장하지만 이것이 공식 최소 인원을 바꾸지는 않는다. APK 직접 설치·내부 테스트 기간·이 문서 작성일은 비공개 테스트 참여 기간을 대신하지 않는다. [Google 공식 요건](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko)
