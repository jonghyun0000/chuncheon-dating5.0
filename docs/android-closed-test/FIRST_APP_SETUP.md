# 춘천과팅 최초 Play 앱 생성

2026-11-18 사용자 확인: 개인 개발자 계정은 약 1년 전 만들었으며, 춘천과팅 앱 생성·AAB 업로드 이력은 없다. 기존 패키지나 등록된 업로드 키에 맞추는 절차는 필요하지 않다. **아래는 입력 준비 자료이며 Console 앱 생성 완료 기록이 아니다.**

## 앱 만들기 입력값

[Google Play Console](https://play.google.com/console/)에서 **앱 만들기**를 연다.

| 항목 | 입력값 |
| --- | --- |
| 앱 이름 | 춘천과팅 |
| 패키지 이름 | `kr.hyundo.chuncheondating` — 준비된 AAB와 동일. Console에서 등록 가능 여부 확인 |
| 기본 언어 | 한국어 — `ko-KR` |
| 앱 / 게임 | 앱 |
| 무료 / 유료 | 무료 — 앱 다운로드 가격. 나중에 앱 내 유료 기능을 추가하는 경우는 별도 설계·신고 필요 |
| 연락 이메일 | 현재 서비스 문의 주소 `john_1217@naver.com`이 실제 수신·운영 가능한지 확인한 뒤 입력 |

개발자 프로그램 정책·미국 수출법·Play 앱 서명 서비스 약관은 계정 소유자가 내용을 읽고 해당 선언을 확인한다. 실제 화면에서 필수 입력을 완료한 뒤 앱 만들기를 누른다. 패키지 이름은 고유하고 영구적이므로 복사해 입력하고 오탈자를 확인한다. [Google 앱 생성 공식 안내](https://support.google.com/googleplay/android-developer/answer/9859152?hl=ko)

## 생성 후 상태

- Console 대시보드의 신원·연락처·기기 확인 등 미완료 작업을 확인한다.
- [등록정보 초안](STORE_LISTING_DRAFT.md)을 사용해 소개글을 준비한다. 카테고리 후보는 데이트, 테스트 국가 후보는 대한민국이다.
- 현재 후보 AAB의 패키지는 위 값이며 versionCode는 `1`, 버전은 `1.0.0-beta.1`이다. 실제 등록 전 `BUILD_REPORT.json`과 대조한다.
- 기존에 만든 로컬 업로드 키를 유지한다. 안전한 백업을 확보하고 첫 릴리스의 Play 앱 서명·업로드 인증서 설정에서 사용한다. 업로드 키와 Google의 앱 서명 키는 역할이 다르며, 비밀키 파일을 Console 입력란이나 대화에 붙여넣지 않는다.

**앱 생성만으로 테스트 배포나 14일 참여 기간이 시작되지 않는다.** 현재 후보는 운영 차단 적용·삭제/정책 보완·의존성 감사·실기기 검증 등이 남아 있다. [검증 결과와 배포 전 조건](VALIDATION_AND_NEXT_STEPS.md)을 충족한 후 [비공개 테스트 실행 안내](RUNBOOK.md)에 따라 제출한다.

현재 연결 도구로 Play Console의 생성 화면을 직접 조작하지 못했다. 생성 뒤 앱 이름·패키지가 표시된 Console 앱 주소로 생성 상태를 이어 확인할 수 있다. 비밀번호·API 키·서명키를 공유할 필요는 없다.
