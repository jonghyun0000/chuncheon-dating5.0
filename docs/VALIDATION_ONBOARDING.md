# 가입·팀 등록 개선 검증

운영 적용 전 검토용. 운영 배포/DB 변경은 승인 대기.

## 범위와 근거

- 기준 운영 SHA: e4d87607dbbf281f8ef62459cd6eef10ca5a1048.
- Supabase 읽기 전용: profiles/teams/team_drafts/match_requests/member_photos 컬럼 및 RLS, 실제 공개 RPC와 참여 조건, 신청 INSERT 정책, private 버킷 확인.
- `can_participate`: 활성 + is_verified + approved. 신청 INSERT: 본인 발신 팀, pending, 상대/인원 조건. 사진/학생증 버킷 비공개. 프론트엔드 안내로 권한을 대체하지 않음.
- 개인정보/사진 파일/운영 사용자 세션을 다운로드하지 않음. 운영 테스트 가입·팀 작성·신청 없음.
- `npm run check`: 타입 검사, 102 단위 테스트 및 Vite 빌드 통과.
- `npm run test:db`: 73/73 보안·기능 회귀, 과거 개인정보 삭제와 4개 동시성 케이스 통과. 운영 DB가 아닌 로컬 PostgreSQL 17 가상 데이터.
- 브라우저 테스트는 390×844 모바일 뷰포트, 가상 API/이미지 사용. 실제 Supabase 호스트 요청 차단.

## 브라우저 검증 항목

가입·둘러보기·비공개 초안 수정/재조회·인증 제출/대기·승인 후 공개·첫 신청/대기/성사 결과, 일반 회원 관리자 진입 차단, 관리자 양 성별 조회/MFA, 사진 없는 저장, 3명 선택 사진 저장, 사진 부분 실패 재시도, 관리자 사진 보관함, 오류 재시도, 다국어, 모달 접근성.

신규 검증: 이탈 취소 시 입력 유지, 수정 취소 확인, 브라우저 뒤로가기 계속/나가기, 저장 성공 후 경고 해제, 잘못된 학번 옆 오류·포커스, 심사 상태 링크, 승인·공개 단계 안내, 첫 신청/결과 연결.

새로고침 관련: cancelable beforeunload 이벤트가 취소되는 것은 양 엔진의 테스트로 확인한다. OS/브라우저의 실제 네이티브 경고는 보장하지 않는다. Chrome 자동화에서 실제 reload 경고 테스트는 종료 대기가 발생해 종료했으며, 네이티브 경고 통과 결과로 계산하지 않았다. 모바일 강제 종료 복원은 구현하지 않았다.

## 테스트 실행 중 해결한 사항

- 새 라우터를 반영하도록 기존 로딩 복구 단위 테스트를 MemoryRouter에서 createMemoryRouter로 변경. 오류 검증 조건은 유지.
- 동시에 실행한 두 Vite 빌드가 dist를 덮어써 첫 브라우저 실행에 환경설정 오류가 발생. 이후 브라우저 빌드를 순차 실행하여 분리.
- 미저장 폼을 가진 테스트 브라우저가 종료 시 네이티브 경고에 머무르는 것을 방지하도록 afterEach에서 명시적으로 떠나기 처리. 앱의 실제 경고 로직은 유지.

## 보존/복구

- SQL migration, 서버 함수, RLS, 개인정보/사진 보관 기간 변경 없음.
- 추가 진단 SQL은 SELECT 집계만 수행하며 결과에 사용자 식별값이나 파일 경로 없음.
- 현행 사진 재동의 요구·90일 보관·사진 없이 이용·닉네임 아래 배치 유지.
- 승인 후 앱만 배포. 문제 발생 시 직전 운영 배포로 복구하며 데이터 복원 불필요.
- 실제 전환율 개선은 아직 미측정. ONBOARDING_AUDIT.md의 지표 정의와 한계 참고.
